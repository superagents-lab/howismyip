## Findings considered and rejected (so they aren't re-audited)

- **`process.env` won't carry secrets on Cloudflare Workers** — rejected. With
  `nodejs_compat` + compat date `2025-09-02`, Workers populates `process.env`
  from secrets; the paid providers activate as intended. By-design, works.
- **ip-api.com called over plain HTTP** — noted, not planned. HTTPS requires
  ip-api's paid tier; plaintext server-to-server geo lookup of an already-public
  IP is a documented external constraint, low signal.
- **`detectClientIp` trusts client headers** — folded into plan 002. On
  Cloudflare `cf-connecting-ip` (checked first) is trustworthy, and any IP is
  already lookable via `/api/ip`, so header spoofing is not a privilege
  escalation — only the resulting crash/divergence mattered, which 002 fixes.
- **No XSS / no IP-param injection** — verified clean: React escapes all output;
  every IP is `isValidIp`-gated and `encodeURIComponent`'d before reaching
  upstream URLs. Nothing to plan.
